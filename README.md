# Titanic Survival Prediction

A machine learning classification project based on the Kaggle Titanic competition.

## Project Overview

The goal is to predict passenger survival based on demographic and travel-related features.

## Topics Covered

- Exploratory Data Analysis
- Data Cleaning and Preprocessing
- Handling Missing Values
- Feature Engineering
- Categorical Feature Encoding
- Classification Models
- Model Evaluation

## Tools & Technologies

Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook

## Project Structure

The `notebooks` directory contains the analysis, preprocessing, and model development steps.
